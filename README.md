# Expense Tracker with Charts

A clean, fully client-side Expense Tracker built with HTML, CSS, and JavaScript.
No backend required — all data is stored in the browser's localStorage.

# Features
➕ Add income and expense transactions with category, date, description & amount
📊 Monthly Totals bar chart — compare income vs. expenses month-by-month
🍩 Category Breakdown doughnut chart — see where your money goes
📅 Month filter — view summary and charts for any specific month
💾 localStorage persistence — data survives page refreshes
🗑 Delete individual transactions or clear all at once
📱 Responsive design — works on mobile, tablet, and desktop
